# Space Is for Everyone

A space-themed activity studio for elementary school students. The home page shows progress across six subject planets and lets students choose the next mission. In an activity, the subject chooser and one short lesson idea at a time stay in the side panel, while a live creative activity fills the main area. Students can pack a rocket, model a planet, compose a field report, design a mission patch, build a rocket, and plan a crew. There are no quiz questions.

Finishing an activity awards a subject badge, lights up its planet on the mission board, and suggests another unfinished subject. Completing all six unlocks a printable Space Explorer Certificate. Lesson position, creations, completed planets, and badges save automatically in browser `localStorage`. Existing saved creations and progress from the earlier activity studio are retained on the same device and browser.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server. There are no packages, frameworks, or build steps.

## Publish on GitHub Pages

Push these files to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, then choose the branch and **/(root)** folder. The site uses relative paths, so it also works from a repository subpath.
